# Кандзи · сакура (версия 1.2)

Справочник и тренировка японских кандзи. PWA: ставится на телефон, после первой загрузки работает без интернета.

## Как опубликовать (так же, как приложение с карточками)
1. Загрузите **все файлы и папку icons** в репозиторий GitHub (в корень или в отдельную папку).
2. Settings → Pages → Deploy from a branch → ветка main, папка / (root).
3. Откройте ссылку на телефоне в Chrome → меню ⋮ → «Установить приложение».

## Как обновить с первой версии
Замените файлы в репозитории новыми (все, включая новый stats.js). Откройте приложение, закройте и откройте ещё раз:
подтянется новая версия. Ваши кандзи, правки, категории и прогресс сохраняются.
Перед обновлением всё же сделайте копию: Настройки → «Сохранить копию».

## Что нового в 1.2
- **Кандзи дня** (вкладка «Учить», самая верхняя карточка): каждый день случайная подборка из нескольких кандзи. По каждому нужно написать иероглиф на холсте, затем ответить на кунное и онное чтение. Подбор с уклоном в трудные: те, где вы чаще всего ошибались или нажимали «не знаю» (по всем режимам, включая карточки), выпадают заметно чаще. Количество кандзи в подборке: Настройки → «Кандзи дня». Кнопка «Другие кандзи» меняет подборку. Занятие засчитывается в серию-цветок и в статистику.

## Что было нового в 1.1
- Русские значения списком (кнопка 訳 в справочнике): видно кандзи и английский перевод, Enter — к следующему, «Сохранить» — всё разом.
- Светлая тема (по умолчанию), тёмная и «как в системе»: Настройки → Тема.
- В письме: Ctrl+Z — отменить черту, Ctrl+Y или Ctrl+Shift+Z — вернуть, Enter — проверить / дальше. Работает и на русской раскладке.
- Статистика: серия дней в виде цветка сакуры, календарь, графики, прогресс по уровням, сложные кандзи.
- Классические флэш-карты: «Кандзи → чтения», «Чтения → написание», вперемешку; кнопки «выучено» / «не знаю».
- Исправлено «null» в интерфейсе.

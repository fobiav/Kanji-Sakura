# Кандзи · сакура

Справочник и тренировка японских кандзи (PWA, работает офлайн после первой загрузки).

## Как опубликовать (так же, как приложение с карточками)
1. Загрузите **все файлы и папку icons** в репозиторий GitHub (в корень или в отдельную папку).
2. Settings → Pages → Deploy from a branch → ветка main, папка / (root).
3. Откройте ссылку на телефоне в Chrome → меню ⋮ → «Установить приложение».

## Как обновлять
После замены файлов в репозитории откройте приложение, закройте и откройте ещё раз:
новая версия подтянется. Данные (кандзи, правки, прогресс) при этом сохраняются.
Если меняете файлы, увеличьте номер VERSION в sw.js.
